✅ How is Core-Set Sampling Different from BADGE?
Feature	               | Core-Set (K-Center Greedy)           	                        | BADGE (Gradient Embedding + Diversity)
                       |                                                                |
📐 What it uses 	   | Embeddings from the penultimate layer of the model	            | Gradient embeddings: ∇loss w.r.t. classifier weights
🎯 Focus	           | Pure diversity in feature space	                            | Combines uncertainty + diversity
🤖 What it assumes	   | Embedding space captures semantic similarity	                | Classifier gradients reflect model confusion + representation
🧮 How it selects	   | Greedy selection of points farthest from current labeled set	| Clustering (k-means++) in gradient space
🏗️ Output structure    | Sample furthest from labeled set until budget is filled	     | Cluster centers in gradient space → pick closest sample
❌ Does it use labels  |                                                                |
or predictions?	       | No (only embeddings)	                                        | No labels, but pseudo-labels are used to simulate training
🧠 When it’s best  	   | You want diverse coverage of the space (e.g., medical images)	| You want diverse + confusing samples (uncertainty + diversity)

🔍 Visual Intuition

BADGE:

Treats each sample as a direction in gradient space: “how would this sample change the model if trained on?”
Then clusters those gradient directions

Core-Set:

Treats each sample as a location in semantic space: “what kind of feature does this sample represent?”
Then selects samples that span that space as broadly as possible
